05 QUESTIONS

Frequently asked questions

Browse the documentation
What is bapX Agents?

bapX Agents brings coding agents into one desktop app. Work in your project, give parallel tasks separate Git branches, or connect to a private Linux Core.

Read the bapX Docs
How can I get the desktop app?

Public app downloads are not available yet. When a package is verified, this page will direct you to the installer for your platform.

Check app availability
How do I run my own Core?

Start with a dedicated Ubuntu 24.04 machine. Install Core and the Codex CLI, sign in to Codex, then pair the desktop app using the Core’s HTTPS URL and token.

Read the private Core setup guide
Can a coding agent help me set up bapX?

A coding agent can help you follow the desktop build instructions for your platform. Review the commands it proposes and sign in to your own coding provider when prompted.

Read the build instructions
Which agents and accounts can I use?

The desktop app integrates with Codex, Claude Code, Cursor, Pi, OpenCode, and more. Which agents you can start depends on the machine you select and the accounts you set up. The private Core guide uses Codex for the initial setup.

Set up Codex on your Core
What costs should I expect when self-hosting?

You provide the Linux machine and the account or API key your coding agent uses. Hosting and model costs depend on the services and plans you choose.

Can a task continue if I close my laptop?

Tasks running on your private Core can continue while the Linux machine stays online. Reconnect from the desktop app to reopen the thread. Local tasks need the computer running them to stay awake.

Where are my repository, history, and keys kept?

Your repository and session history live on the private Linux machine. Private Core is for one trusted user, with threads sharing that machine. The guide keeps service credentials separate from the coding agent’s account. Your agent connects to the model provider you configure.

Read how Core stores session history
